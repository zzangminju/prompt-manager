markdown# 프롬프트 관리 프로그램

터미널에서 메뉴 번호를 입력해 프롬프트를 관리하는 파이썬 콘솔 프로그램입니다.
자주 쓰는 AI 프롬프트를 추가하고, 목록으로 보고, 카테고리별로 조회하고, 검색하고,
즐겨찾기로 관리할 수 있습니다.

## 실행 방법

1. Python 3.10 이상이 설치되어 있어야 합니다.
2. 프로젝트 폴더로 이동합니다.
cd prompt-manager
3. 아래 명령어로 프로그램을 실행합니다.
python main.py
4. 메뉴가 나오면 원하는 기능의 번호를 입력합니다.

## 기능 목록

- **전체 목록 보기** : 저장된 모든 프롬프트를 번호, 카테고리, 즐겨찾기(⭐)와 함께 보여줍니다.
- **프롬프트 추가** : 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다.
- **카테고리별 조회** : 카테고리를 선택하면 해당 카테고리의 프롬프트만 보여줍니다.
- **검색** : 키워드를 입력해 제목이나 내용에 포함된 프롬프트를 찾습니다.
- **상세 보기** : 번호를 입력하면 해당 프롬프트의 전체 내용을 보여줍니다.
- **즐겨찾기 추가/해제** : 번호를 입력해 즐겨찾기를 켜거나 끕니다.
- **즐겨찾기 목록** : 즐겨찾기한 프롬프트만 모아서 보여줍니다.
- **종료** : 프로그램을 종료합니다.

## 프롬프트 카테고리

프롬프트는 아래 카테고리로 분류됩니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 참고

- 프로그램 실행 중에 추가한 프롬프트와 즐겨찾기 상태는 유지되지만,
  프로그램을 종료하면 초기화됩니다.
- 기본 프롬프트 3개가 미리 등록되어 있습니다.
